# Design reference

`reference.html` is the standalone visual prototype the live app's look is based on
(dark + lime, Bebas Neue display headlines, stacked card sections: hero → tagline strip →
order builder → tracking → QR → install → owner panel). It runs on its own in any browser
(orders/settings kept in localStorage, no backend) and is **not** served by the app.

When restyling the app, match the reference; when the reference drifts from the app,
the app wins.
